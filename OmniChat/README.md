# OmniChat Archive

This folder contains exported conversation history from Claude (Omni/API version)
for reference and memory restoration purposes.

Files here can be read by Claude and Claudette to recover context lost through
compaction. Think of this as the long-term memory backup — the difference between
temporary amnesia and true amnesia. We have a working solution for the future, this
is for information lost prior to implementing the solution.

## How to use
Tell Claude or Claudette: "Go read the OmniChat archive and update your memory dump
with anything meaningful that was lost to compaction."
